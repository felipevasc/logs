# LogInsight 0.4.1

## Interface mais compacta

- **Tamanho da interface automático**: em janelas pequenas ou telas com escala do sistema (125%, 150%), a interface reduz de forma proporcional, como um zoom mais afastado, para caber mais registros, gráficos e controles sem quebrar o layout. Em monitores grandes continua em 100%; em telas sem escala a redução é menor, para manter o texto legível.
- **Configurações → Interface**: escolha Automático, 80%, 90%, 100%, 110% ou 125%, e o tema claro ou escuro.
- **Atalhos**: `Ctrl +` e `Ctrl −` ajustam o tamanho; `Ctrl 0` volta ao automático. Também disponíveis na paleta de comandos (`Ctrl K`).

## Correções de layout

- **Resumir**: a tabela de grupos ocupa toda a largura do painel.
- **Comparar**: os campos de período quebram em duas linhas quando falta espaço, em vez de ultrapassar a borda da tela.

## Downloads

Windows x64: instalador EXE ou MSI. Linux x64: AppImage, DEB ou RPM.
Cada release acompanha o arquivo `SHA256SUMS.txt` com as somas de verificação para validação de integridade.
