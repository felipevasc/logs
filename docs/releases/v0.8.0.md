# LogInsight 0.8.0

## Busca por texto com índice invertido

- A busca por texto livre usa um índice invertido, como os mecanismos de busca: para cada palavra, o aplicativo já sabe quais registros a contêm. Com 3 milhões de registros, uma busca repetida responde em 0,02 a 0,17 s, e o tempo quase não cresce com o volume.
- Os resultados continuam exatamente os mesmos: o índice só encontra os candidatos, e a conferência final usa o mesmo teste de antes. Buscar parte de uma palavra ("time" encontra "timeout") continua funcionando.
- Identificadores longos (trace ids, hashes) são agrupados no índice, para que não o inchem nem deixem a primeira busca lenta.
- A preparação da primeira abertura de um arquivo passa a montar também esse índice e fica mais demorada.

## Casos

- Cada Caso guarda a própria análise: filtros, colunas, agrupamentos e visões. Trocar de Caso restaura a análise dele e consulta novamente os registros; um Caso novo começa com a análise limpa sobre as mesmas fontes.
