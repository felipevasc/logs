# LogInsight 0.17.1

- **Versões não são mais lidas como data:** textos como `Apache httpd 2.4.62`, `libxml 2.9.14` ou `10.10.10.10` deixavam de ganhar datas falsas (2062, 2014…) na linha do tempo. Datas como `12.10.2026` e qualquer data com hora continuam reconhecidas. As fontes abertas são reprocessadas uma vez ao reabrir.
- **Novo formato "Rótulo: valor":** registros com pares `Rótulo: valor` separados por tabulação ou espaços (por exemplo `Host: … Ports: …`) viram campos `label.*`, sem alterar o que o leitor já extraía. Só vale quando quase todas as linhas têm essa forma.
- **Saída do nmap (`-oG`):** cada host ganha `destination.ip`, `host.name`, contagem de portas abertas, fechadas e filtradas, serviços e a lista `nmap.ports`; o comando e a versão vêm do cabeçalho.
- **Colunas: todas as ocorrências no registro:** quando o padrão acha o valor mais de uma vez, a opção guarda todos juntos, separados por vírgula (portas, endereços, nomes repetidos).
- **SQL: uma linha por item de lista:** `unnest` está liberado, com exemplos "Lista em linhas" e "Uma linha por porta (nmap)".
- Linhas que começam por `#` ganham o campo `comentario`. Nada que já funcionava foi alterado: uma linha de base com 38 arquivos de formatos diferentes confere cada leitura.

Os instaladores e suas assinaturas são publicados após as verificações automáticas de Windows e Linux.
