# LogInsight 0.13.4

- Conexões com o **Wazuh**. **Wazuh · indexer** importa alertas, eventos arquivados, achados, eventos normalizados e vulnerabilidades, de onde o painel do Wazuh lê os dados. Funciona do Wazuh 4.0 ao 5.0, com conjuntos prontos que preenchem índice e campo de horário.
- **Wazuh · API do servidor** importa o inventário de agentes. Usuário e senha geram o token de acesso, renovado automaticamente durante importações longas. Também é possível colar um token.
- O teste de acesso informa a versão real do indexer, quantos registros o conjunto escolhido tem, outros conjuntos Wazuh disponíveis, índices sem permissão e a geração detectada (4.x ou 5.x). Endereços trocados entre indexer, API e painel recebem orientação específica.
- **Certificado CA** aceita a autoridade própria das instalações do Wazuh (`root-ca.pem`). A opção explícita de não validar o certificado é para redes confiáveis. Ambas também valem para Elasticsearch e Kibana.
- Alertas Wazuh usam o nível da regra como severidade, a regra como código e a descrição como mensagem. Origem, usuário, host, processo, arquivo e hash, inclusive de eventos Windows, alimentam os campos canônicos; grupos de autenticação classificam logons.
- Horários ISO com fuso sem dois-pontos, como `2026-10-08T12:00:00.000+0000` do Wazuh e do Suricata, passam a ser lidos com o fuso correto.

Validação inclui testes do conector com servidores locais que reproduzem o Wazuh indexer 4.x e 5.x e a API do servidor, testes de leitura dos alertas e o fluxo da página Conexões no navegador. Os instaladores e suas assinaturas são publicados após as verificações automáticas de Windows e Linux.
