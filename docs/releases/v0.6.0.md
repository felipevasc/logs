# LogInsight 0.6.0

## Atualizações automáticas

- Ao abrir, o LogInsight verifica no GitHub se há uma versão nova e pergunta antes de baixar: **Atualizar agora**, **Mais tarde** ou **Pular esta versão**. Nada é baixado ou instalado sem confirmação.
- O download mostra o progresso e permite continuar trabalhando. Com o pacote pronto, **Reiniciar e instalar** salva os casos, instala e reabre o aplicativo; **Instalar ao fechar** deixa a instalação para quando a janela for fechada.
- Cada pacote é conferido pela assinatura e pela versão assinada antes da instalação. O instalador do Windows (`.exe`) e o AppImage atualizam sem senha de administrador; `.msi`, `.deb` e `.rpm` pedem a senha.
- Na primeira abertura de uma versão nova, os casos e as configurações são copiados para `backups/` na pasta de dados, com as três cópias mais recentes guardadas.
- **Configurações → Atualizações** mostra a versão instalada, a última verificação, **Verificar agora** e a opção de verificar ao abrir. A variável de ambiente `LOGINSIGHT_UPDATES=0` desativa as atualizações em ambientes isolados ou geridos por TI.

## Publicação

- `npm run release -- X.Y.Z` alinha a versão, cria o commit e a tag; o envio da tag testa, gera, assina e publica a versão. Qualquer pessoa com permissão de escrita no repositório publica, sem segredos a configurar.
- Antes de publicar, o workflow instala uma versão de teste e confirma que ela se atualiza sozinha no Windows e no Linux, e confere cada pacote como os aplicativos instalados farão.

## Como instalar esta versão

Quem usa a 0.5.x instala a 0.6.0 manualmente uma vez; a partir dela, as próximas versões são oferecidas pelo próprio aplicativo. Prefira o `.exe` no Windows e o `.AppImage` no Linux. Detalhes em [Atualizações](https://github.com/felipevasc/logs/blob/main/docs/atualizacoes.md).

## Downloads

Windows x64: instalador EXE ou MSI. Linux x64: AppImage, DEB ou RPM. `SHA256SUMS.txt` acompanha os arquivos; `latest.json` e os `.sig` são usados pelo atualizador.
