# LogInsight 0.14.2

- **Filtro em texto nas importações:** o campo Filtro das conexões Elasticsearch, Kibana e Wazuh aceita a mesma escrita da barra de busca do painel Wazuh e do aplicativo, como `rule.level >= 10 and agent.name: web*`. Há `campo: valor`, `and`, `or`, `not`, parênteses, aspas para a frase exata, curingas, `campo: *` para exigir o campo, comparações, faixas, listas de valores e blocos de endereços. O aplicativo converte o texto para Query DSL e mostra a consulta enviada enquanto você digita. Query DSL em JSON continua aceita.
- **Teste de acesso pelo painel Wazuh:** "Testar acesso" na conexão Wazuh · painel web não falha mais com erro 400.
- **Orientação mais clara:** o tipo Wazuh · indexer apontado para o endereço do painel agora sugere usar Wazuh · painel web.

Os instaladores e suas assinaturas são publicados após as verificações automáticas de Windows e Linux.
