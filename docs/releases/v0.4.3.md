# LogInsight 0.4.3

## Carregamento mais elegante

- Menus, abas e áreas que estão carregando mostram duas linhas finas que deslizam em sentidos opostos e se cruzam como ondas, discretas, rente à base do item. O ícone do status no rodapé segue o mesmo movimento.

## Downloads

Windows x64: instalador EXE ou MSI. Linux x64: AppImage, DEB ou RPM.
Cada release acompanha o arquivo `SHA256SUMS.txt` com as somas de verificação para validação de integridade.
