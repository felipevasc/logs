# LogInsight 0.4.4

## Carregamento como processamento

- Menus, abas e áreas que estão carregando ficam esmaecidos por um véu, e duas linhas finas atravessam o item de ponta a ponta: ondas que correm em sentidos opostos, se cruzam e pulsam como um batimento ou uma voz sendo processada. O ícone do status no rodapé segue o mesmo movimento.

## Downloads

Windows x64: instalador EXE ou MSI. Linux x64: AppImage, DEB ou RPM.
Cada release acompanha o arquivo `SHA256SUMS.txt` com as somas de verificação para validação de integridade.
