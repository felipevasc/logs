# LogInsight 0.13.5

- Nova conexão **Wazuh · painel web**: importa alertas, eventos arquivados, achados, eventos normalizados e vulnerabilidades usando o endereço do painel do Wazuh, o mesmo aberto no navegador, com usuário e senha do painel. Não é preciso acesso direto ao indexer (porta 9200).
- Links copiados do navegador podem ser colados como estão: o trecho a partir de `/app/` é descartado.
- As consultas passam pelo console de Dev Tools do painel e oferecem os mesmos conjuntos prontos, período, filtro, teste de acesso e detecção de versão do Wazuh 4.x e 5.x. A conta precisa ler os índices `wazuh-*` e usar o Dev Tools; login SSO do navegador não é reutilizado.

Validação inclui testes do conector pelo console do painel com um servidor local e o fluxo da página Conexões no navegador. Os instaladores e suas assinaturas são publicados após as verificações automáticas de Windows e Linux.
