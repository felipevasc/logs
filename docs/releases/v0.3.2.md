# LogInsight 0.3.2

## Seleção de registros sem caixas de seleção

- Tabela de exploração aprimorada: seleção limpa por destaque de cor nos registros, sem caixas de seleção (checkboxes).
- Suporte a seleção contígua por intervalo com `Shift + clique` e seleção acumulada/alternada com `Ctrl + clique` (ou `Cmd + clique`).
- Suporte ao atalho universal `Ctrl + A` / `Cmd + A` para selecionar todos os eventos visíveis da tabela.
- Ao clicar com botão direito em qualquer registro selecionado, mantém a seleção múltipla e permite jogá-los para uma trilha nova ou existente.

## Integração MCP e Kibana moderno (v0.3.1 consolidado)

- Servidor MCP completo com 50 ferramentas nativas e instruções de configuração para Google Antigravity.
- Compatibilidade expandida com Kibana 7.x, 8.x e 9+.
- Retenção cumulativa de fontes de dados e gerenciamento granular de arquivos no Workspace.

## Downloads

Windows x64: instalador EXE ou MSI. Linux x64: AppImage, DEB ou RPM.
Cada release acompanha o arquivo `SHA256SUMS.txt` com as somas de verificação para validação de integridade.
