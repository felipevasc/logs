# Java trace preview fixture

`java-traces.json` was generated by the actual Rust Java parser and serializer. Each case keeps decoded `raw` and the queryable scalar `fields` separate from the rich `detail` envelope. The preview mock supplies that envelope only for `java_trace_detail`; it never adds the rich object to an Event or a normal query page.

The complete sample has Unicode, 30 retained frames, cause/suppressed branches, native/unknown/file locations and shared-frame elision. The incomplete sample retains uncertain frames and diagnostics. The source SHA and generation description are embedded in the JSON. `generate-java-traces.rs` is the generator used by the isolated native harness with its already-built serde, serde_json and sha2 dependencies. It reads `src-tauri/src/java_stacktrace.rs` when run from the repository root.

The browser scenario enables the fixture explicitly. It demonstrates UI/admission transport behavior against serialized native parser output; it is not an installed desktop, full source import or performance benchmark.
