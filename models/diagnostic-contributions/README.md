Contribuições diagnósticas opcionais usam o esquema fechado `DiagnosticContribution`.
Não coloque logs, justificativas, nomes, timestamps ou referências de eventos aqui.
Origem e episódio recebem recibos aleatórios persistentes; revisões posteriores do
mesmo episódio substituem os rótulos anteriores na consolidação.

O workflow consolida até 4096 episódios. O ranking limita a influência por origem
e reserva origens inteiras para avaliação. Uma base também precisa passar nos
controles sintéticos locais antes de ser aceita pelo aplicativo. Esses controles
não estabelecem precisão representativa nem calibram probabilidades.
